# Distance Calculator

## Description

The Distance Calculator is a Python program that calculates the distance between two points. It uses the distance formula to find the distance based on the x and y coordinates entered by the user.

## How to Run the Program

1. Open the `distance_calculator.py` file in a Python editor or IDE.
2. Run the program.
3. Enter the x and y coordinates when asked.
4. The program will calculate and display the distance.

## Input Needed

The program needs four numbers:

* x1 - x-coordinate of the first point
* y1 - y-coordinate of the first point
* x2 - x-coordinate of the second point
* y2 - y-coordinate of the second point

## Sample Output

```text
Enter x1: 1
Enter y1: 2
Enter x2: 4
Enter y2: 6
The distance between the two points is: 5.0
```
